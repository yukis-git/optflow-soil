# フーチング沈下デモ

合成した動画データで、「ROI の設定 → 追跡 → 真値との比較」までを 1 コマンドで通して見せるデモ。
砂地盤の模型実験で剛なフーチング(帯基礎)を押し込んだ場面を合成し、設定した ROI の中の土を、最初のフレームの
位置から追跡する。真値(変位・ひずみ)は解析的に分かっているので、推定との差をそのまま精度として示せる。

## 1 コマンドで実行

```sh
cd python
.venv/bin/python -m demo.run_demo                  # リポジトリのルートから: python python/demo/run_demo.py
```

出力は既定でリポジトリのルートの `demo_out/`(git 管理外)。Rust の実行ファイル
(`rust/target/release/optflow`)が無いときは `cargo build --release -p optflow-cli` を自動で実行する。

## オプション

| オプション | 既定 | 内容 |
|---|---|---|
| `--out DIR` | `demo_out/` | 出力先。同じ場所に前回の出力があれば、このデモが書いたファイルだけを置き換える(他のファイルは触らない) |
| `--size small\|full` | `full` | `full`: 1280×720、60 フレーム、沈下 30 px(s/B = 0.2)。`small`: 384×216、6 フレーム、沈下 6 px(s/B = 0.133)。スモークテスト用で、**精度は全サイズよりずっと低い**(楔の幅が 60 px ほどでトラッカーのフィルタより狭く、強い帯で楔の推定が遅れる。沈下を 9 px にすると最終フレームで楔が全部無効になる) |
| `--frames N` | 60 (small: 6) | フレーム数(フレーム 0 が参照) |
| `--settlement PX` | 30 (small: 6) | 最終フレームの沈下量 [px]。s/B が約 0.3(全サイズで約 45 px、小サイズで約 13 px)を超えると、凍結した機構が土を折り返して det F が 0.3 を下回るので、始める前に拒否する(終了コード 2) |
| `--impl rust\|python` | `rust` | 追跡に使う実装。`python` は遅い参照実装(全サイズで数十分〜) |
| `--no-animation` | | `strain_animation.mp4` を作らない |
| `--set KEY=VALUE` | | トラッカーの設定の上書き(繰り返し可)。例: `--set max_disp=48` |
| `--keep-fields` | | トラッカーのフレームごとの `.npy`(フルサイズで 1 フレーム約 30 MB)を消さずに残す |
| `--reuse` | | 前回の動画とトラッカーの出力(`--keep-fields` で残したもの)から、図・動画・summary だけ作り直す。前回の変位場のパラメータが今回と違うときは拒否する |
| `--bin PATH`, `--no-build` | | Rust の実行ファイルの場所 / 無いときに自動ビルドしない |
| `--seed N` | 1 | テクスチャとノイズの乱数の種 |
| `--quiet` | | エラー以外を表示しない |

トラッカーの設定の例: `--set shape_order=2`(局所の変位モデルを 2 次にする)を付けると、帯の中の精度が上がる(フルサイズの実行で、最終フレームの
変位誤差 RMS 0.123 → 0.049 px、帯の中 0.44 → 0.16 px、99 パーセンタイル 0.68 → 0.21 px、ガード外の有効率 0.94 → 0.95、楔の画素の有効率(最終)0.55 → 0.89)。
ただし沈下の初期はノイズが約 1.4 倍(変位誤差 RMS 0.014 → 0.019 px)になり、最終フレームの Exx の帯の中の誤差(0.046 → 0.075)はむしろ増えるので、
既定は変えていない。

## 見るところ

1. `strain_animation.mp4`: 沈下の初期(フレーム 10 付近)には、フーチングの縁の下に縦長の拡散したせん断(破壊前の流れの縁の帯)が見える。
   沈下とともに、フーチングの縁から楔(V 字)のせん断帯が現れて強くなり、その外側に、縁を中心とする
   対数らせん状の曲がった帯(扇形の外縁、深さ約 1 B まで下がる)が現れ、そこから地表へ向かう直線の帯(受働楔の底)につながる。
   受働楔は外向きと上向きに押し出されるので、地表が隆起する(縁の脇に峰、その外側に平らな台地)。ROI の輪郭は土と一緒に動く。
2. `overview.png` の gmax の行(推定・真値・誤差): 帯の位置と形は合い、帯の中で推定のピークが低く広がる(せん断帯の幅が
   追跡の窓と同程度のため)。誤差が帯の縁、楔の頂点、フーチングの縁に集まる。
3. `curves.png`: 沈下曲線(推定が、楔の中の土の真値に重なる)、精度の推移、そして**真値の体積収支**
   (フーチングが押し込んだ面積、隆起した面積、脇の沈下部、土の面積の正味の変化の、沈下に対する変化)。
4. `summary.md` の表(特に「物理モデルと文献との対応」)と「誤差が大きい場所とその理由」。

## 合成モデル(`footing.py`, `field.py`)

- **場面**: 1280×720 px。砂状のスペックル(帯域を絞ったノイズ+粗い粒+ゆるい濃淡)の土、動かない容器の壁
  (壁にマーカ)と背景、フーチング(幅 B = 150 px、荷重棒付き)が地表中央から一定の速さで沈む(最終 s = 30 px、s/B = 0.2)。
  土槽は内幅 1120 px、深さ 350 px で、機構の出口は壁から 160 px 以上、底は機構の最大深さの 1 B 以上下。
  カメラノイズ 0.4 %、フレームごとの照明ゆらぎ ±0.6 %、H.264 (crf 12)。
- **変位場**(`field.py`): u(X; s) = s_e(s) U_e(X) + s_m(s) U_m(X)。形状関数 U_e、U_m は s によらないので、一連のフレームは
  s_e、s_m の 2 つのスカラーの線形結合で安く作れる。勾配は自動微分(2 変数の双対数)で厳密に出す。逆写像は厳密なヤコビアンのニュートン法。
  運動学だけのモデルで(応力も荷重もなく、ピーク荷重の判定もない)、沈下の履歴 s(t) と s_p は与えたもの。
  - **時間変化(進行性破壊)**: s_e = s_p tanh(s/s_p)(s_p = 0.06 B、拡散した破壊前の部分)、s_m = s − s_e(機構の部分)。
    小さい s では s_m ≈ s³/(3 s_p²) なので、帯は徐々に現れる。フーチングの底面の中央部(|x'| が b − 2w = 49 px まで)の土は (0, s) で
    動く。縁の近く(帯の幅の 2 倍以内)では、正則化した縁のため土が遅れる(s = 30 px で縁では 12 px 遅れ、縁の地表は初期より 18 px 低く、
    フーチングは 12 px だけ土に食い込む)。
  - **U_m(破壊機構)**: 非関連流れ則の Mohr–Coulomb 材料に対して運動学的に許される、剛体ブロック + 対数らせん扇形の機構
    (速度の食い違いがすべり面と ψ の角をなす: Michalowski 1997)。楔(側面の角 α = 60°、(0, 1) で真下に動く)、フーチングの縁を中心と
    する対数らせん扇形(扇形の角 Θ = 64°)、受働楔(外側のすべり線は水平から β' = 30°)。膨張角 ψ = 4° で、すべり面の速度の食い違いが
    すべり面と ψ の角をなして開く(帯の膨張)。押し込んだ体積と帯の膨張は、受働楔の隆起として出て行く(b + D = |X_e − E| f(Θ) cos β)。
    地表の出口は中心から 399 px(2.7 B)、最大深さ 156 px(1.04 B)、楔の頂点は 130 px(0.87 B)。
    **上界解でも、最適化した機構でも、Prandtl の解でもない**(ψ < φ では極限解析の定理が成り立たない。α、β' はせん断帯の向きの理論から取った)。
    帯は幅 w = 13 px の 5 次スムーズステップ(C2 級、ひずみの半値全幅は実測で約 13 px)で、ゾーンの速度を重み付きで混ぜる。
    特異点の 2 か所(フーチングの縁、楔の頂点)は局所的に正則化してある(縁では扇形を絞り、帯を広げる。頂点では帯を広げて丸める)。
    影響の範囲は、縁から 3 w = 39 px、頂点から約 7 w。
  - **U_e(破壊前の部分)**: ほぼ非圧縮の拡散した流れ U_e = (1 − κ) U_iso + κ U_c(κ = 0.07)。密な砂は破壊前にほとんど収縮しない(平面ひずみの要素試験で、拘束圧 4.9 kPa
    で約 0.1 %、392 kPa で 0.5 % 未満: 図から目で読んだ値、Tatsuoka et al. 1986)ので、押し込んだ体積の大半を基礎の脇の隆起として戻す。
    **この「大半を隆起として戻す」割合は仮定で、隆起と押し込みの比を測った文献は見つからなかった**。
    - U_iso は流れ関数 Φ = Ψ(x') K(y') の流れ(u_x = Φ_y、u_y = −Φ_x)で、1 次の発散が厳密に 0。K(y') は地表で 1、深さ L_k = 2.2 B で 0
      (C2 級、地表で K' = 0 なので地表の u_x は 0、底は粗い)。フーチングの下では Ψ = −x' で、土はフーチングと一緒に沈み(u_y = 1)、深さとともに外へ広がる。
      基礎の脇では Ψ が 0 に戻り、中心から b + L_h = 315 px(L_h = 1.6 B)まで続く隆起の裾になる。縁には半幅 w_e = 3 w = 39 px の帯があり、
      そこで鉛直の流れが下向きから上向きに変わる(ひずみが縁に集中する)。
    - U_c は基礎の下の圧縮の塊(鉛直だけ)。基礎の底では U_iso と合わせて土がフーチングと同じだけ動き、押し込んだ面積 B·s_e の κ を吸収する。
    - 場は |x'| ≥ b + L_h と深さ L_k、L_c(2.2 B)以下で厳密に 0(容器の壁と底の近く、50 px 以内で |det F − 1| < 1.5×10⁻⁴)。
    - **体積ひずみ**(真の行列式 det F − 1): −0.0049〜+0.0122。圧縮の最小 −0.49 % は、要素試験の 0.1〜0.5 % の上端(392 kPa の値)に当たり、
      数 kPa の模型基礎の下の応力に対応する下端(約 0.1 %)の数倍。κ は、最小が −0.005 を
      下回らない最大の値(κ = 0.07。0.1〜0.2 にすると最小は −0.0059〜−0.0092、最大は +0.0114〜+0.0090)。最大 +1.2 % は縁の脇(|x'| ≈ 95 px、
      深さ ≈ 63 px)で、1 次の発散(≤ 0)ではなく 2 次項 det Hess Φ = −(Ψ'K')² + ΨΨ''KK''。縁の帯のせん断と深さ方向の外向きの流れの変化の積で、
      帯の幅に反比例する(w_e = w だと +3.3 %、帯の脇の体積ひずみの最小が −0.29)。縁の脇の縦長の帯(|x'| = 74〜120 px、深さ 10〜138 px)の
      土の面積の 3 % が +0.2 % を超える。**w_e は w ではなく 3 w にした**(縁の帯の gmax は最大 0.35 で、基礎の下の中央の 0.10 の 3.6 倍。
      w_e = w だと 1.15)。
    - **設計仕様(ブリーフ)からの逸脱**(了承済み、測定値): (1) s_p U_e の det F − 1 は [−0.0049, +0.0122] で、仕様の [−0.005, +0.002] 
      (縁の近傍 [−0.01, +0.005])に収まらない。最小は基礎の下 (x', y') = (−55, 165) px、最大は縁の脇 (−95, 63) px(縁の近傍の外。中は +0.0097)。
      1 次の発散は至る所 ≤ 0 (最小 −0.0025) なので、正の部分は純粋に 2 次項。+0.002 を超えるのは土の面積の 3.3 %、+0.005 を超えるのは 2.0 %。
      縁の帯を持つ流れ関数の流れでは +0.002 は半幅 100 px 超でないと届かない。(2) w_e = 3 w = 39 px(仕様は w 程度。w_e = w だと +0.033)。
      (3) κ = 0.07(仕様は 0.1〜0.2。κ = 0.1 で最小 −0.0059、0.2 で −0.0092)。
    - **滑らかな沈下の立ち上がりと基礎の脇の隆起のための道具で、較正した場ではない**。
- **ひずみの大きさ**: 最終フレームの gmax(主ひずみの差)の 99.9 パーセンタイルは約 1.8、最大約 2.3(縁の特異点の近傍)。帯と扇形の体積ひずみ
  det F − 1 は最大 0.11、det F の最小は 0.77(全域で正)。特異点の近傍だけ正則化のため体積ひずみが縁で最大 +0.75、頂点で −0.23 になる(見かけの値)。
  帯の脇の最小 −0.14 は、破壊前の流れのせん断と機構の帯のせん断の積の項(機構だけなら −0.0005)。
- **真値**: u(X, t) をフレーム 0 の格子(ラグランジュ座標 X)で、ひずみは Green-Lagrange ひずみ E = (FᵀF − I)/2、
  gmax、det F − 1 を `optflow_ref.strain.strain_fields` と同じ式で計算。
- **物理的な意味と限界**(対応表は `summary.md` の「物理モデルと文献との対応」。文献は、読めて確認できたものだけを挙げてある):
  - 運動学だけの様式化した場で、実験で較正していない。形は古典的な楔・扇形・受働楔を運動学的に許される形にしたもの。
    **外側の領域の大きさ(出口 2.7 B、深さ 1.04 B)は様式化した選択で、測定では確かめていない**(見つかった実験の観察では、
    頂点は約 1.15 B で、ここは 0.87 B。古典的な Prandtl の形なら φ = 45° で出口 12 B)。
  - 帯の幅は、ひずみの半値全幅で 13 px(1 px = 0.2 mm、D50 = 0.2 mm と仮定すると 13 D50)で、報告される 7〜20 D50 の範囲。
    帯の体積ひずみ 0.10 は、測定値が見つからず較正していない。ψ = 4° は経過平均の簡略化。
  - 体積収支は定義から厳密に成り立つ(1 次の閉じた式 + 有限変位の 2 次項 + 縁での土とフーチングの重なり)。破壊前の部分の圧縮は
    −κ B s_e(押し込んだ面積 B·s の 2 %)にすぎず、土の面積は正味で増える(最終フレームで +1003 px²: 帯と扇形の膨張 +1458、圧縮 −94、
    有限変位の 2 次項 −337 など)。隆起は総量で押し込んだ面積の 126 %、正味で 117 %。地表は縁で初期より 18 px 低いが、縁から 0.16 B で
    初期の高さに戻り、縁から 0.4〜0.6 B に最大 13 px の峰(破壊前の隆起の裾 + 受働楔の持ち上げ)、さらに外側に受働楔の平らな台地(7.1 px)が
    できる。隆起と沈下の比を測った文献は見つからず、実験との一致は確認していない。`s_p`(`Params.sp_frac`)を小さくしても圧縮・隆起の
    釣り合いはほとんど変わらず、機構の分担が増えて帯のひずみが強くなる(`summary.md` の 3 節に感度がある)。
  - モデル化していないもの: 左右非対称な片側すべり、破壊前の膨張(密な砂はせん断帯ができる前に膨張に転じるが U_e は膨張しない)、
    破壊前の流れの形は固定(振幅 s_e だけが変わる。w_e、L_h、L_k は設計上の値)、隆起の割合(仮定)、ひずみ軟化と限界状態でのダイレイタンシーの飽和(ψ は一定)、帯の幅の変化、
    粒子破砕、機構の幾何の移動(形を固定した機構を s_m に比例させている。そのため体積の変化に有限変位の 2 次項が付く)、
    粗いフーチングの底面(楔は真下にだけ動く)、応力レベルによる φ・ψ の変化、壁の摩擦。

## 実行時間

フルサイズ(60 フレーム)で、負荷の高いマシン(負荷平均 約 3〜21、他のジョブが走っている)で合計 約 5 分だった(動画と真値の生成 約 27 秒、
Rust での追跡 約 4.5 分、評価・図・動画 約 12 秒)。動画の生成は、逆写像を全画素で解くので 1 フレームあたり約 0.45 秒。
静かなマシンではこれより短く、他のジョブが走っているとさらに伸びる(実際の値は `summary.md` の「処理時間」)。`--size small` は 10 秒ほど。
